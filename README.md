# FresherAI

AI-powered career platform for freshers: build resumes, score them, practice mock interviews, and get personalized learning roadmaps.

## Features

- **Resume Builder & Scorer:** AI-assisted resume creation with feedback and score
- **AI Mock Interview:** Practice interviews and get a detailed report
- **Roadmap Builder:** Role-based learning roadmap with YouTube resources per module
- **Auth & Billing:** Firebase login, interview coins system

## Tech Stack

- **Frontend:** React (Vite), Redux, Axios
- **Backend:** Node.js, Express, MongoDB, Redis (microservices + API gateway)
- **AI:** LangChain, LangGraph, Groq API
- **DevOps:** Docker, Docker Compose
